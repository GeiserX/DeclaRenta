# DeclaRenta

Herramienta fiscal gratuita para inversores con brokers internacionales. DeclaRenta lee los informes de tu broker extranjero y calcula las casillas de la renta con FIFO y tipos de cambio oficiales del BCE. Renta Web no importa esos datos, así que sin esto hay que hacerlo a mano.

- [Primeros pasos](getting-started.md): la web, Docker y los botones de despliegue
- [Uso](usage.md): la web y todos los comandos de la CLI
- [Brokers soportados](brokers.md): el formato de fichero de cada broker
- [Modelos fiscales y motor fiscal](modelos-fiscales.md): las reglas que aplica el motor
- [Casillas del Modelo 100](casillas.md): cada casilla con su base legal
- [Traza del motor de divisas (FX)](traza-fx.md): el modo diagnóstico para auditar las casillas 1633/1637
- [Privacidad](privacidad.md): qué datos se procesan y dónde
- [Desarrollo](development.md): tests, build, contribuir y soporte
